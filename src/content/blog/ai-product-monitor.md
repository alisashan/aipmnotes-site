## 业务背景

跨境选品依赖大量分散信息：类目排名、竞品价格、评论趋势、搜索词热度。人工每日刷新既耗时又容易遗漏关键变化。

## 方案概览

```
数据源（API / 爬虫）→ 清洗归一 → 规则 + LLM 摘要 → 告警通道（邮件 / 飞书）
```

## 关键模块

### 数据采集

- 锁定 20–50 个核心竞品 ASIN 与关键词
- 按日抓取价格、评分、BSR、主图变更等字段
- 数据落库（SQLite 或云数据库均可）

### 异常检测

用规则引擎处理硬阈值（价格骤降、评分暴跌）；用 LLM 对评论增量做情感与主题聚类，生成「本周用户抱怨 Top3」。

### 推送策略

| 级别 | 条件 | 动作 |
|------|------|------|
| P0 | 竞品大幅降价 | 即时推送 |
| P1 | 关键词排名波动 | 每日汇总 |
| P2 | 常规周报 | 周一发送 |

## 产品视角的收获

这个项目的价值不仅在自动化，更在于把「该看什么」固化为指标与规则，让选品决策可追溯、可复盘。
